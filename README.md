# Node.js Docker Application

## Project Description

This project is a simple Node.js application that has been containerized using Docker.

The project demonstrates how to:

- Create a Node.js application
- Store the application code on GitHub
- Clone the project to a Linux server
- Build a Docker image
- Push the Docker image to Docker Hub
- Pull the Docker image from Docker Hub
- Run the application inside a Docker container

## Technologies Used

- Node.js
- Docker
- Docker Hub
- GitHub
- Linux
